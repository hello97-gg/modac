## What is ModMC AntiCheat?

It's a lightweight, packet-based anti-cheat for Minecraft servers (1.8–1.21.3). Built on PacketEvents, it catches modern hack clients using math and packet analysis instead of bloated heuristics.

**Why people use it:**
- Zero dependencies to install
- Doesn't lag your server
- Actually catches cheaters
- Configurable down to the details
